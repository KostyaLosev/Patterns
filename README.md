# Shapes (Patterns task)

TypeScript-приложение для работы с фигурами `Triangle` и `Pyramid`.

## Что реализовано
- Entity-классы без бизнес-логики: `Point`, `Shape`, `Triangle`, `Pyramid`.
- Factory Method для создания фигур из строк файла.
- Валидаторы входных данных и геометрической корректности фигур.
- Сервисы вычисления:
  - для треугольника: площадь, периметр, типы треугольника;
  - для пирамиды: площадь поверхности, объём, проверка основания на координатной плоскости.
- Чтение данных из `.txt`, некорректные строки пропускаются.
- Логирование через `pino` в консоль и файл `src/logs/app.log`.
- Unit-тесты на Jest.

## Запуск
```bash
npm install
npm test
npm run build
npm start
```
